# Sources and asset provenance

The tower compiler, editor and content recipes were developed for this project. No general redistribution license has been selected for this repository yet. Public visibility alone does not assign a license to third-party content.

Ragnarok game names and client assets belong to their respective rights holders, including Gravity. The native map importer reads the user's local GRFs; resulting maps, models and textures remain local build outputs. Do not publish those outputs or their ZIP archives from this repository. The original navigation table, client sprites and recordings are not included.

Monster display names and numeric identities are metadata used to select game monsters. Korean names are checked against [Inven Monster DB](https://ro.inven.co.kr/dataninfo/monster/list.php); per-monster evidence and unresolved entries are documented alongside the mapping. Display-name provenance is documented in [LOCALIZATION.md](workshop/full-tower/editor/LOCALIZATION.md). No claim of exact current kRO patch parity is made.

Format and documentation references:

- [Ragnarok Offline](https://github.com/Flux159/ragnarokoffline.app), including [MOD_REGISTRY.md](https://github.com/Flux159/ragnarokoffline.app/blob/main/docs/MOD_REGISTRY.md).
- [MondoTruth/standart-npc](https://github.com/MondoTruth/standart-npc): standalone mod presentation and release conventions.
- [igueradx/ARPG-Equipments-Mod](https://github.com/igueradx/ARPG-Equipments-Mod): standalone mod organization and progression presentation.
- [rAthena](https://github.com/rathena/rathena): server scripting and monster identities. Compatibility depends on the actual installed server revision.

These references are not a claim that their scripts or artwork were copied into this repository, or that their licenses grant rights to Gravity assets.
